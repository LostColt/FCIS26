Build one small thing.

1. Build in Gemini Canvas — one prompt

Slide 19 shows one user message revealed in sections, not a series of imagined replies from Gemini. Select Canvas before giving the prompt. Explain what you want, ask Gemini to make its own more detailed instructions, and ask it to use those instructions to build. Your account and Gemini's response may vary.

The complete example prompt

I want a futuristic interface with a moving particle shape in the middle. I want to move it with my mouse and see computer panels around it.

Turn what I just described into a detailed build prompt for yourself. Include the design, movement, interactions, and things I might have missed.

Then use that prompt to build the application in Canvas.

How the build works

  1. Open Gemini in an account where Canvas is available; select Canvas.
  2. Paste or adapt the single prompt above and submit it. The presentation reveals the text in stages only to make it easier to explain.
  3. Review the output. If Gemini wants clarification or proposes a different approach, respond based on what you actually see. A specific result is not guaranteed.
  4. Try the preview, request one change in ordinary language, and test the revision.
  5. Keep your source: copy the code if available, download an export where supported, and open the resulting app to test it independently. Controls may vary by account, platform and output type.

The interactive HUD example is an existing HTML file, not a live Gemini response. The presentation's Copy code, Download HTML, and Open app controls operate on that actual demo file. You can also download the example HTML from this resource page.

For a classroom example, use the twelve subject-and-grade tools plus learning-support starters. Keep student information out of unapproved services.

2. Export to Google Sites, then publish

The screenshots in the presentation show the real controls: in Gemini Canvas choose Export → Google Sites, then use the Google Sites editor to review and publish the page. This direct export creates a new private draft; it does not automatically make the page public. The school Google Workspace account shown here is a useful demonstration, but Google also lists personal Google accounts and Workspace Individual among eligible users. Controls and permissions may differ.

  1. Once the interactive app works in Gemini, choose Export → Google Sites on the app.
  2. Google Sites opens a new private draft with the interactive app included. Review the result, title and page layout.
  3. Choose Publish in Google Sites. Review the site's web address and sharing/audience settings before confirming.
  4. Open the published address in another browser session, ideally signed out, to verify what visitors can actually access.

Important: Export does not automatically make the site public. This route requires Google Sites access and permission to create and edit sites; organizational Google Drive and Sites policies still apply. If Export → Google Sites is unavailable in your account, look for Export → Download code in Canvas (as shown in the workshop screenshots). You can save the HTML and use a school-approved hosting method, or share the Canvas link where permitted.

Data: Use invented examples for demonstrations. Shared Gemini apps may have stored or shared data, so review settings carefully and do not use an experimental public app for student records.

Sources: Google Workspace announcement, October 19, 2026 · Gemini Canvas help · Google Sites help

3. Make a classroom tool

Choose from twelve purpose-built examples across lower, middle, and high school Math, English, Science and History. Each starts with something students need to understand, explain, test or revise. You can also choose learning supports for reading access and other needs, including dyslexia.

Open the single-screen classroom prompt workbench. Choose Grade and Subject on the left and watch the editable prompt change on the right; Learning support is another grade-menu option. Add Reading, Language, Focus or Visual design guidance as needed, then copy the complete prompt. In Gemini, select Canvas and paste it. The prompt asks Gemini to elaborate its own build instructions and create a first version, which you can test and revise.

The prompt library does not send information to a model or store your edits on a server. Teachers remain responsible for verifying accuracy, accessibility and student privacy.

4. Prototype → Store → Host

You do not need to complete all three stages today. Start with a prototype you can test. When you want to return to the work, decide where the project or code will live. Only publish when someone else needs to use it.

Two kinds of storage: Saving the code is not the same as storing information that students enter. A small static tool may need no database. Apps that save records, use accounts, or connect to services require a separate data and privacy plan. GitHub is for source code, not identifiable student records.

The most accessible paths can handle prototype and hosting in the same product. More technical paths separate building, source control, and hosting. Use whichever path fits the scope—not every classroom idea needs GitHub or Vercel.

5. ChatGPT Work — build a Site without coding

Start inside ChatGPT Work, not a regular ChatGPT conversation. Codex is also an OpenAI/ChatGPT coding product, but it is a different path for working on project files. ChatGPT Sites creation in Work is available only where supported by plan and workspace permissions.

  1. Open ChatGPT on the web and select Work; the ChatGPT desktop app also offers supported workflows.
  2. Ask Work to build a website for the classroom need, or reference @Sites. Describe the grade, learning objective, and interaction.
  3. Test the private preview, ask for a revision, and check how it works on a student device.
  4. Keep the Site in the ChatGPT workspace. When ready, deploy it and check Share access carefully: a newly deployed Site is not automatically public.
Build a simple interactive website for [grade and subject]. Students need to practice [learning objective]. Give them [two meaningful actions], clear directions and a fictional example. Keep it usable on a Chromebook or phone, and do not collect student names or grades. Let me test a private preview and ask for changes before publishing.

6. More control — working with real code

These are short starting directions, not an in-session assignment. Codex belongs to OpenAI's ChatGPT family; Antigravity belongs to Google's Gemini ecosystem. Claude Code is Anthropic's coding route. They can work on actual files, so make a copy of your project, inspect proposed edits, and test before publishing.

Google AI Studio — browser-based app building

Open Google AI Studio · Official Build mode guide · Publishing options

  1. Open Build and describe a small application; test the live preview and revise.
  2. In Settings, use the GitHub connection to link or create a repository, or download a ZIP of the source.
  3. When ready, use the available Publish/Cloud Run flow, checking account eligibility, permissions and potential billing. If hosting code elsewhere, configure required server-side secrets safely.

Claude — start with an artifact, then consider Claude Code

Open Claude · Download Claude Desktop · Claude Code first-day guide

  1. Try an interactive artifact in Claude for a small prototype, or install Claude Desktop and open its Code tab for a coding project (where your plan allows).
  2. For Claude Code, choose a local project folder, ask for one change, review the resulting files and test.
  3. Save code to GitHub if you want version history. Share the artifact using its permissions, or deploy a compatible coded project via a host such as Vercel.

Codex — ChatGPT's coding agent

Download ChatGPT desktop · Codex documentation

  1. Open the available Codex experience in the ChatGPT desktop app (or use a supported Codex coding environment).
  2. Open or create a project folder, explain your desired tool and ask for a first working version. Review the file changes and run the application.
  3. Save the source to GitHub, then import a compatible repository into Vercel if you want a public URL. Codex is for code development, not a requirement for ChatGPT Work Sites.

Google Antigravity — Gemini-powered development

Download Antigravity · Official getting-started guide

  1. Install the desktop application for your operating system and sign in with an eligible Google account.
  2. Create a project, add a local folder, and ask the agent to build a small prototype. Inspect its plan, code changes and test results.
  3. Keep the files in the local folder and use GitHub for version control; deploy a supported web app through Vercel or another suitable host.

Two services you may need later

GitHub — store and version your code

Create an account · First repository walkthrough

Create a repository for the project, push or upload its files, and commit revisions. Keep passwords, API keys and student data out of source control.

Vercel — host a compatible web app

Create an account · Deploy from GitHub

Import the repository, review the framework and root folder, configure any environment variables, and deploy. Verify the resulting URL before sharing it.

Before you publish: Check third-party services, subscription and school restrictions; verify any generated facts, accessibility and privacy; test the site without your own logged-in permissions. GitHub stores application source, while a tool that collects data may require a separate, approved storage service.

Before you share with students

Use mock information during development. Check AI-generated explanations, answer keys and links. Never submit names, grades, essays or student records to unapproved services. Check who owns the account, where information is stored, who can see it, and who maintains the tool later. Keep your LMS and gradebook as the systems of record.

When building reading supports, give learners choices rather than assuming one setting helps everyone. Read-aloud, spacing, contrast and focus views can be useful options, but they do not replace structured literacy instruction or school accommodations.

Start small. Let one colleague try it. Keep what works, and revise the rest.
