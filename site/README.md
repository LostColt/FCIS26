# site

The live deck and the mockups. Open `index.html` directly, or see it on Vercel.

- `index.html`, `css/`, `js/`: the swipeable deck. The words are in `js/slides-a.js` and `js/slides-b.js`.
- `assets/fonts/`: Literata and IBM Plex Sans, stored locally (SIL Open Font License).
- `demos/`: the five clickable mockups, each self-contained with a `thumb.png`.

Rules are in `BRIEF.md` sections 7, 8 and 8a.
