Save your scripts to Google Drive

Right now your scripts live only in this browser, on this computer. Set this up once and Script Room saves to a Script Room folder in your Google Drive: one file per script, any length. Open it on any computer you sign into and your scripts are there; changes go both ways.

  1. Go to script.google.com, signed in to your school account, and choose New project.
  2. Delete what's in Code.gs and paste this in:
  3. Click + next to Files, choose HTML, name it Index, delete what's there, and paste in this whole tool:
  4. Save. Then Deploy → New deployment → type Web app. Execute as: Me. Who has access: Only myself. Click Deploy.
  5. Google asks for permission to use your Drive. That's normal: it's your own script, saving to your own Drive.
  6. Open the web app link and bookmark it. That's your Script Room from now on.

Already have scripts here? Export a backup first, then Import it in the new link.
