What could you build for your classroom?

Choose a grade band and a subject. Copy a starting prompt, change the brackets, then try it in Gemini Canvas or another builder. These are starting points, not finished lessons.

Adapt it for a particular learner

Accessibility is not a separate app. Ask the builder to keep the original learning goal while offering choices such as read-aloud, adjustable size and spacing, captions, keyboard access and fewer distractions. Test these options with users. No single font or color works for everyone with dyslexia.

Keep the learning goal and content unchanged. Add optional reading supports: read-aloud with pause and replay where available, adjustable text size and line spacing, a distraction-reduced view, clear button labels, visible keyboard focus and captions or transcripts for any audio. Keep every setting optional. Do not collect student names, responses or other personal data. Show me how to test each option.

One way to use any prompt

Make a first version. Try it as a student. Ask for one specific change. Check the content and interaction yourself. Follow school rules before sharing; these prompts use fictional content and should not contain student information.
